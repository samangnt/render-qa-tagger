# 🎥 Render Guard — AI Animation Auditor (video_qa.py)

Upload a 3D playblast and approved script. 
AI audits the animation and returns timestamped 
feedback with a Readiness Grade (A-F).

## Tech Stack
- Python + Streamlit
- Google Gemini (Video Analysis)
- Google File API
